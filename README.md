# 🎓 Campus Placement Predictor

Campus Placement Predictor is an AI-powered web application that predicts campus placement chances for students based on their academic profile and experience. It provides an interactive, visually appealing interface with personalised feedback, profile breakdowns, and actionable improvement tips — helping students understand where they stand and what to focus on before campus recruitment drives.

---

## 🪟 Project Overview

This application allows students to:

- **Enter their academic details** — CGPA, 10th/12th marks, board, stream
- **Record their experience** — internships, projects, trainings, backlogs, communication & technical skills
- **Get an AI-powered placement prediction** — powered by a Random Forest model trained on 3,000+ student records
- **View a visual profile breakdown** — score bars for CGPA, communication, internships, projects, backlogs
- **Receive personalised recommendations** — prioritised by urgency (critical → improve → strengths)
- **Navigate seamlessly** across three pages: Home → Input Form → Results
- **Enjoy interactive animations** — confetti/fireworks for placed results, rain drops for needs-improvement

All predictions are generated locally using pre-trained model artifacts. The application is designed for educational use and campus placement preparation.

## 🏃🏻‍♀️‍➡️ How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/yourusername/campus-placement-predictor.git
cd campus-placement-predictor
```

### 2. Create a virtual environment
```bash
python -m venv venv

# Windows
venv\Scripts\activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Train the model (first time only)
```bash
python train_model.py
```

This will:
- Load and preprocess `Dataset/Placements_data.csv`
- Train a Random Forest classifier with 5-fold cross-validation
- Save all model artifacts to the `models/` folder
- Generate a confusion matrix plot

### 5. Run the Streamlit app
```bash
streamlit run app.py
```

The app will open automatically at `http://localhost:8501`

## ☁️ Deploy to Streamlit Cloud

### Step 1: Prepare your GitHub repository

Make sure your repo has these files committed:
```
app.py
requirements.txt
Dataset/Placements_data.csv
models/          ← IMPORTANT: must include all .pkl files
```

**Note:** `styles.css` is optional for cloud — the app has inline CSS fallback. But you can include it too.

### Step 2: Create a `packages.txt` (if needed)
Some deployments need system packages. Create `packages.txt`:
```
# packages.txt
# (leave empty or add if you need system-level dependencies)
```

### Step 3: Deploy on Streamlit Cloud

1. Go to [share.streamlit.io](https://share.streamlit.io)
2. Sign in with GitHub
3. Click **"New app"**
4. Select your repository
5. Set **Main file path** to `app.py`
6. Click **Deploy**

The app will build and deploy automatically. You'll get a public URL like:
```
https://yourusername-campus-placement-predictor-app-abc123.streamlit.app
```

### Important for Cloud Deployment

- The `models/` folder **must** be in your GitHub repo (Streamlit Cloud can't run `train_model.py` during build)
- The `Dataset/` folder is needed if you want to retrain, but `models/` is sufficient for inference
- All `.pkl` files are binary — they won't show in GitHub's preview, but they will deploy correctly

## 📌 About the `.pkl` Files

The `models/` folder contains **binary serialized files** (`.pkl`) — these are:

| File | What it stores |
|------|----------------|
| `random_forest.pkl` | Trained model weights and decision trees |
| `scaler.pkl` | Feature scaling parameters |
| `label_encoders.pkl` | Mappings for categorical text → numbers |
| `feature_columns.pkl` | Exact column order the model expects |
| `ohe_categories.pkl` | One-hot encoding category mappings |
| `model_metrics.pkl` | Accuracy, AUC, CV scores, top features |

You **cannot open them in a text editor** — they are loaded by Python using `joblib.load()`. This is standard practice for ML model deployment. Do not commit these to Git — add `models/` to `.gitignore`.

**For Streamlit Cloud:** You **must** commit the `models/` folder to GitHub since the cloud can't generate them during deployment.
